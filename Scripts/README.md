# Local scripts

For source execution, put custom scripts here. For the standalone release, create this folder beside `dist/Toolkit.ps1` or your copied Toolkit.ps1 instead.

Use `.ps1`, `.bat`, or `.cmd` in this folder or one immediate subfolder. Keep supporting files in `_support`. Refresh Custom Scripts in the toolbox. Optional metadata uses the full script filename plus `.json`. See the root README for the format.
