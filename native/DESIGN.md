# TOOLX desktop design

Direction approved in this session: MMC / professional Windows utility; Indonesian and English. Antislop DURING.

ENERGY 1 / RHYTHM 2 / MOTION 1. Dense command lists, readable detail panels and a single blue selection accent. A command's name, risk and available action provide the focal point; spacing distinguishes navigation, parameters and results. No decorative animation.

Use a resizable category tree, sortable command table, split detail/results view, compact toolbar and status bar. These expose a large catalog without decorative dashboard cards. Text wordmark TOOLX and by ALSA preserve the existing identity; no new logo or stock assets.

Segoe UI supports native Windows reading and localization. Consolas is reserved for command output. Neutral surfaces and visible borders suit the approved MMC direction. System, Light and Dark share resources; High Contrast uses Windows brushes. Data grids scroll within their own panels. Test 100%, 150% and 200% DPI, keyboard focus and empty/error/running states.

Every action has a real implementation. External Windows tools are marked as launched, not as completed repairs. No fabricated health scores or performance claims. English provider identifiers and unmodified Windows error text remain technical data, even when the interface is Indonesian.
